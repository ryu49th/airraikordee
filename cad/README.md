# AirRaiKorDee — ไฟล์ CAD สำหรับพิมพ์ 3D

มี 2 ชุด
1. **ชิ้นทดสอบ** (`test_coupons.py` → `out/01…09_*.stl`) พิมพ์ก่อน เพื่อหาค่าระยะเผื่อที่เข้ากับเครื่องพิมพ์ของทีม
2. **ชิ้นจริงครบทั้งเครื่อง** (`airraikordee_parts.py` → `out/parts/`) 21 แบบ (19a/19b เลือกอย่างใดอย่างหนึ่ง) (ครีบบานลม 4 ชิ้น)

ทุกขนาดอยู่ใน `P` ด้านบนของ `airraikordee_parts.py` แก้ค่าแล้วรัน `python3 airraikordee_parts.py` ใหม่ ไฟล์ทั้งหมดจะสร้างใหม่ให้เอง
**ค่าที่ติดคำว่า `MEASURE` ยังเดาจากสเปกทั่วไป ต้องวัดของจริงก่อนพิมพ์ชิ้นใหญ่**

## ขั้นตอน
1. พิมพ์ชิ้นทดสอบ แล้วจดค่าตามตารางท้ายไฟล์นี้
2. วัดของจริง (รายการด้านล่าง) แล้วแก้ใน `P`
3. รัน `python3 airraikordee_parts.py` แล้ว `python3 check_fit.py` ต้องขึ้น `pairs flagged: 0` และส่วนหัวหมุนต้องไม่มีรายการชน
4. พิมพ์ชิ้นจริง

## สิ่งที่ `check_fit.py` ตรวจแล้ว
- ทุกคู่ชิ้นในเครื่องประกอบ (ชิ้นพิมพ์ + กล่องแทนของซื้อ) ซ้อนกันไม่เกิน 0.5 mm³ → **ผลตอนนี้ 0 คู่**
- หมุนหัวไปที่ 0°, 30°, 90°, 135°, 179° พร้อมหมุนเฟืองเล็กตามอัตราทด แล้วเช็กว่าชิ้นที่หมุนไม่ชนชิ้นที่อยู่นิ่ง → **ไม่ชน** รวมถึงเฟืองเล็กกับเฟืองวงแหวน (ซ้อนกัน 0 mm³)

## สิ่งที่เปลี่ยนจาก CLAUDE.md เดิมระหว่างทำ CAD
- **เฟืองวงแหวน 87 → 89 ฟัน** เฟืองเล็กอยู่ที่รัศมี 77 แทน 75 อัตราทด 7.42:1 เพราะมอเตอร์ Ø28 ใส่ช่องระหว่างพัดลมกับผนังที่กว้าง 27.5 ไม่ได้ ผนังหัวจึงนูนออก 1.5 มม. ตรงมอเตอร์ด้านขวา
- **เฟืองเล็กกลับหัว (ดุมลงล่าง)** อยู่ใต้พื้นหัว แกนมอเตอร์ยาวพอเพราะพื้นตรงมอเตอร์บางเหลือ 2 มม.
- **ความสูงรวม ≈ 384 มม.** (ฐาน 85 + ช่องกรอง 174 + บ่ารอง 10 + แหวน 20 + หัว 92 + ฝา 3)
- **แผงเบนลมเป็นแผ่นเอียง 45°** แทนโค้งหนึ่งในสี่ เพื่อให้พิมพ์คว่ำพร้อมฝาได้โดยไม่ต้องใช้ support
- **Jetson ยกสูงบนเสา 16 มม.** เพื่อคร่อมขอบรางแบต ฐานจุแบต 70 × 55 กับ Jetson 100 × 80 ได้พอดี
- **สายจากรางหลังวิ่งในร่องบนบ่ารองไปที่แกนกลาง** ขาไขว้ด้านหลังของแหวนทำหน้าที่ปิดร่องนี้ แทน "spoke" ที่เป็นชิ้นแยก
- **วัดของจริงแล้ว:** ลูกปืนหนา 10 (เดิมเดา 8) รูยึดห่าง 82 · แหวนกลับมาสูง 20 เท่าเดิม (ใช้ 09 ที่พิมพ์ไปแล้วได้): แผ่นบนของลูกปืนหมุนไปพร้อมหัว มุมลูกปืนจึงไม่ผ่านเฟืองเล็ก เสายึดใต้หัวสั้นลงตามอัตโนมัติ · พัดลม TL-C14CW หนา 25
- **สเต็ปเปอร์ไม่ยึดด้วยหูแล้ว:** หัวสกรูที่หูจะโผล่ใต้พื้นหัวที่รัศมี 87 = ฟันเฟืองวงแหวน → ชนตอนหมุน เปลี่ยนเป็นแผ่นรัด (18) กดจากด้านบนลงเสา 2 ต้น ช่องมอเตอร์เป็นร่องยาว ±1.5 ไว้ปรับระยะฟัน
- **หัวแบ่งเป็น 2 ชิ้น + ตลับกล้อง:** 11a (ล่าง) ประกอบลองหมุนได้ก่อน แล้วค่อยต่อ 11b (บน) ด้วยสกรู 4 ตัว · กล้องเป็นตลับ 19a/19b ถอดจากด้านนอกได้
- **ใต้หัวเรียบ:** เสายึดลูกปืน (20) กับขาชนสวิตช์ (21) แยกเป็นชิ้นขันสกรูติด หัวส่วนล่างพิมพ์ได้โดยไม่ต้องใช้ support
- **ช่องสเต็ปเปอร์ใช้รูปทรงมอเตอร์จริง:** หูยึด 42 × 7, กล่องสายสีฟ้าหันออกด้านนอก + ช่องให้สายงอขึ้น 3 มม. → ผนังหัวด้านขวานูนออกถึงรัศมี ≈ 105 · ปรับระยะเฟืองได้ −0.5…+1.5 มม. · เฟืองเล็กรูกลมช่วงบน 2 มม. (แกนจริงกลมก่อนถึงส่วนแบน) · `check_fit.py` ใช้รูปทรงมอเตอร์จริงแล้ว
